# 纸上旧书 · 经典文学二十种

Twenty original literary book-jacket studies, drawing on Chinese classical, modern, and international classics. A responsive, lightweight gallery with category filters and an accessible full-size viewer.

## Live

- Demo: https://xiaosang.cc/classic-literature-covers/
- Source: https://github.com/holynova/classic-literature-covers

## Run locally

Open `index.html` from a static HTTP server, for example `python3 -m http.server 8000`.

## Deploy

The site is mounted under `/classic-literature-covers/` on the xiaosang.cc portfolio Worker. The same source repository contains the static files and release receipt.
